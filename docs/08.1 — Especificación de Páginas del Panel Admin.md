## 1. Introducción

Este documento especifica cada página del panel de administración web de QuickBite: qué secciones contiene, qué muestra cada sección, qué acciones ofrece, qué estados puede tener y a dónde lleva cada acción. El objetivo es que cualquier desarrollador o agente pueda construir cada página sin ambigüedad.

La arquitectura, la gestión de estado, la autenticación y la integración con la API residen en el documento 08. El sistema de diseño y los componentes visuales residen en el documento 09. Las decisiones canónicas (polling, servicios externos, pagos simulados, etc.) residen en el documento 05. Este documento no repite ninguno de esos contenidos.

---

## 2. Convenciones

### 2.1. Estructura de cada ficha

Cada página se documenta con:

- Identificador único.
- Nombre.
- Ruta.
- Propósito.
- Secciones (con contenido y acciones).
- Estados (vacío, carga, error, éxito).
- Navegación de salida.
- Endpoints consumidos.
- Decisiones aplicables.

### 2.2. Codificación de páginas

| Prefijo | Categoría |
| :--- | :--- |
| ADM-AUTH | Autenticación |
| ADM-DASH | Dashboard |
| ADM-ORD | Gestión de pedidos |
| ADM-PROD | Gestión de productos |
| ADM-CAT | Gestión de categorías |
| ADM-DEL | Gestión de repartidores |
| ADM-REP | Reportes |
| ADM-CONF | Configuración |
| ADM-AUD | Auditoría |
| ADM-PROF | Perfil del administrador |
| ADM-COM | Transversales |

### 2.3. Convenciones de acciones

| Término | Significado |
| :--- | :--- |
| Acción primaria | Botón principal de la página, color primario |
| Acción secundaria | Botón con menor énfasis |
| Acción destructiva | Acción que elimina o revierte información, con confirmación |
| Acción masiva | Acción aplicada a múltiples elementos seleccionados |
