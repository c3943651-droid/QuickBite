# Especificación: Integración de Google Maps y Ubicación GPS para Delivery

## 1. Objetivo

Integrar la visualización de mapas interactivos (`google_maps_flutter`) y la gestión de permisos/servicios de localización GPS (`geolocator`) en la aplicación móvil Flutter de QuickBite (`mobile`).

Permitirá a los repartidores:
- Visualizar un mapa interactivo con ubicación de origen (restaurante o posición actual del repartidor) y ubicación de destino (cliente).
- Trazar la ruta de entrega mediante una polilínea (`Polyline`).
- Adaptar visualmente el mapa al modo claro y oscuro respetando el Design System (`AppColors`).
- Gestionar de forma segura los permisos de ubicación GPS en primer plano (`locationWhenInUse`) y segundo plano (`locationAlways`), verificando que los servicios de ubicación del dispositivo estén activados.

## 3. Estructura del Código

- **`mobile/pubspec.yaml`**: Inclusión de las dependencias `google_maps_flutter` y `geolocator`.
- **`mobile/lib/src/features/delivery/domain/models/location_permission_status.dart`**: Enum o Value Object representativo del estado de permisos (GPS deshabilitado, denegado, concedido en primer plano, concedido en segundo plano, denegado permanentemente).
- **`mobile/lib/src/features/delivery/data/location_permission_service.dart`**: Servicio para consultar y solicitar permisos de GPS usando `geolocator`.
- **`mobile/lib/src/features/delivery/presentation/widgets/map_styles.dart`**: Definiciones de estilos JSON para Google Maps en modo claro (Light Mode) y modo oscuro (Dark Mode, alineado a `AppColors.nightBackground` y `AppColors.nightSurface`).
- **`mobile/lib/src/features/delivery/presentation/widgets/delivery_map.dart`**: Widget reusable `DeliveryMap` con parámetros:
  - `origin` (`LatLng`): Coordenadas de origen.
  - `destination` (`LatLng`): Coordenadas de destino.
  - `routePolyline` (`List<LatLng>`): Coordenadas de la ruta.
  - `originTitle` / `destinationTitle` (`String?`): Títulos de los marcadores.
  - `onMapCreated` (`Function(GoogleMapController)?`): Callback opcional.
  - `isDarkMode` (`bool?`): Forzado manual o auto-detección del tema actual (`Theme.of(context).brightness`).
- **`mobile/test/features/delivery/`**: Tests unitarios del servicio de ubicación y tests de widget para `DeliveryMap`.

---

## 4. Estilo de Código y Design System

- **Colores de la app**:
  - Polilínea de ruta: `AppColors.accent` (`#0D9488` Teal).
  - Fondo del mapa oscuro: Estilo JSON personalizado ajustado a `#0B1220` (Night Background).
  - Marcadores de origen y destino utilizando iconos visuales distintivos o configuraciones de marcadores con matiz (`BitmapDescriptor.defaultMarkerWithHue`).
- **Clean Architecture & Patrón Repository/Service**:
  - Encapsular llamadas a `GeolocatorPlatform` dentro de `LocationPermissionService` inyectable para soportar TDD y mocking limpio.

## 5. Estrategia de Pruebas (TDD)

1. **Pruebas unitarias para `LocationPermissionService`**:
   - Test 1: Verificar comportamiento cuando los servicios de ubicación GPS están deshabilitados.
   - Test 2: Verificar solicitud y resultado de permisos cuando el permiso es denegado o concedido (primer plano vs segundo plano).
   - Test 3: Manejo de caso cuando el permiso fue denegado permanentemente (`deniedForever`).
2. **Pruebas de widgets para `DeliveryMap`**:
   - Test 1: Renderizado del widget `DeliveryMap` con coordenadas de origen, destino y polilínea.
   - Test 2: Comprobar generación de marcadores (`Marker`) de origen y destino.
   - Test 3: Cambio de tema (modo claro vs oscuro) aplicando los estilos correspondientes.
